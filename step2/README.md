# Step 2 — HTML の完成と基本の CSS（レイアウトなし）

## このステップのゴール

HTML をこのステップで完成させ、CSS の土台（デザイントークンとリセット）を作る。
フォントと文字色・リンク色が変わり、リストの点が消える。

## やること

### HTML（コンテンツを完成させる）

1. `<head>` に Google Fonts（Inter / Zilla Slab）の読み込みと `style.css` へのリンクを追加する
2. ヘッダーのテキストロゴ「MDN」を SVG ロゴに差し替える
3. ヘッダーの下に、パンくずリスト入りのサブ・ヘッダー（`<nav class="sub-header">`）を追加する
4. 記事カードを 4 件コピーして追加し、合計 6 件にする
5. フッターにリンク集の 3 列（MDN / Contribute / Developers）を追加する

### CSS（`style.css` を新規作成）

1. **デザイントークン**: `:root` にカスタムプロパティで色とフォントを定義する
   （このステップで使う分だけ。残りは Step 3 で追加する）
2. **リセットと基本設定**:
   - `* { box-sizing: border-box; }`
   - `body` … 余白のリセット、フォント、文字色、背景色
   - `img` … `display: block` と `max-width: 100%`（親からはみ出さない）
   - `a` … リンク色と下線の制御（ホバー時のみ下線）
   - `ul, ol` … 余白とリストマーカーのリセット

## 学ぶポイント

- **カスタムプロパティ（CSS 変数）**: 色やフォントを 1 か所にまとめて `var()` で使い回す
- **Web フォントの読み込み**: `preconnect` + `<link rel="stylesheet">` の定番パターン
- **リセット CSS**: ブラウザのデフォルトスタイルを整えてから作り始める理由
