# Step 1 — HTML の基本コンテンツ（CSS なし）

## このステップのゴール

CSS を使わずに、ページの「骨組み」となる HTML を書く。
ブラウザのデフォルトの見た目のままで OK。

## やること

1. HTML の基本構造（`<!DOCTYPE html>`、`<html lang="ja">`、`<head>`、`<body>`）を書く
2. ページを 3 つの大きなブロックで組み立てる
   - `<header>` … テキストのロゴ「MDN」と、`<nav>` + `<ul>` によるメニュー（9 項目）
   - `<main>` … `<h1>` の見出しと、記事カード 2 件
   - `<footer>` … ブランド名・キャッチコピーとコピーライト
3. 記事カード 1 件を `<article>` で作り、もう 1 件はコピーして中身を書き換える（この時点では 2 件のみ）
   - サムネイル画像（`alt` を忘れずに）
   - `<h2>` の記事タイトル
   - 著者情報の行（アバター画像・著者名・`<time>` による日付・読了時間）
   - 要約文と「Read more」リンク

## 学ぶポイント

- **セマンティック HTML**: `header` / `nav` / `main` / `article` / `footer` を役割どおりに使う
- **画像のアクセシビリティ**: 意味のある画像には `alt` で説明を、装飾的な画像には `alt=""` を付ける
- **class 属性**: 後のステップで CSS から使う「名前」を先に付けておく（この時点では見た目に影響しない）

## 表示の確認

`index.html` をブラウザで開く。スタイルなしの縦一列の表示になるが、
見出し・リスト・画像・リンクが正しい構造で並んでいれば OK。
